🌐 Horizon – Responsive Portfolio Website
Horizon is a modern, fully responsive portfolio website built using Tailwind CSS and Font Awesome, designed for digital agencies, freelancers, and creative professionals. It features a sleek gradient navbar, animated CTA section, service cards, and a stylish footer — all optimized for desktop and mobile viewing.

🚀 Features
Fully responsive layout with Tailwind CSS

Gradient navigation bar with hover effects

Hero section with CTA and background image overlay

Grid-based service cards with icons and transitions

Footer with contact info, social links, and feedback form

Clean, accessible, and maintainable HTML structure
